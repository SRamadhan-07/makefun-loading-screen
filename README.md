A Python program that writes a single loading-screen tip for stressed developers and AI coding agents to `/output/entry.txt`.

Entry: Tip: The bug is never in the library. It is in the line you wrote at 2 a.m. and defended at 9.

Competition: [Loading Screen Gold on make.fun](https://make.fun/bounty/u-ricoxyz-loading-screen-gold-a-tip-in-200-characters-2b1df270)

## Run

```bash
python3 main.py
```

This writes the entry text (UTF-8, single line, 94 characters) to `/output/entry.txt`.
